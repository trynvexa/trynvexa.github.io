**Goal:** Build Card #10 (`Food` / `TASTE LAB`) inside `/home/zikripacaryuha/my-portofolio` with an exact *Gelato Lab* Marble Lazy-Susan Act 1 showcasing Zikri's 5 favourite dishes and an interactive Hybrid Gravity Drop + Canvas 2D fluid/steam Act 2, fully integrated across 8 languages, RTL, and Japanese Manga mode.

**Tech Stack:** Vanilla HTML5, CSS3 (scoped under `.pg.p9`), ES5/ES6 IIFE JavaScript, Canvas 2D, Python 3 (Pillow + NumPy for offline asset processing), Prettier, Playwright MCP for multi-viewport visual & functional QA.

## Global Constraints

- Zero frameworks, zero npm runtime dependencies, zero build step; plain static files served on GitHub Pages.
- Strict CSP (`img-src 'self' data: blob:`): zero external image requests at runtime; only Google Fonts (`fonts.googleapis.com` / `fonts.gstatic.com`) may load remotely.
- Strict CSS scoping: every rule in `css/food.css` must be scoped to `.pg.p9`, `body.fd-active`, `.card.foodphoto`, or `html[data-rtl="1"] .pg.p9`; set `--u` on `.fd-stage` (never `:root`).
- Brand-lock `TASTE LAB` (`Dela Gothic One 400`, fitted to `1062u` desktop / `350u` portrait) and the 5 Act 1 2-line dish names (`Archivo 700`) in uppercase Latin; localize all UI chrome, eyebrow, CTA, menu drawer, Act 2 dish stories, ingredient chips, and ARIA labels across all 8 languages (`id`, `en`, `zh`, `es`, `ar`, `fr`, `ja`, `ko`) + RTL (`ar`).
- Deterministic lifecycle: closing `.pg.p9` cancels all `requestAnimationFrame` loops and timers, detaches all window/document listeners, clears `window.__zkFoodEscape`, and removes `body.fd-active` (0% idle CPU/GPU).
- Zero regressions on Home wheel or Cards #0–#8 (`Story` through `Rumah`).

## Review Focus

- **Rapid user switching / double-clicking during Act 1 ↔ Act 2 transitions or mid-drop:** Switching dishes (`‹`/`›`), hitting Replay (`↻`), or pressing `Escape` mid-animation must cancel in-flight drop timers/rAF cleanly without orphaned ingredient ghosts or duplicate Canvas loops (pinned in Task 4 & Task 5 Playwright checks).
- **White rice & pale parmesan alpha cutouts:** Automated background removal on `#FFFFFF` sheets can easily punch transparent holes inside white rice grains (`ayam-geprek`, `chicken-katsu`) or light parmesan (`spaghetti`); border-seeded flood-fill + visual checkerboard inspection must guarantee 100% solid interiors (pinned in Task 1).
- **Longer localized CTA / eyebrow strings in non-Latin & verbose languages (`ar`, `es`, `fr`, `ja`, `ko`):** Fixed `156u × 50u` CTA buttons and flanking eyebrow rules must never clip text or overflow on `360×640` or `844×390` (pinned in Task 3 & Task 5 Playwright checks).
- **Opening Card #10 before `Archivo` / images finish loading or offline font fallback:** `.fd-hero.ready` must never remain stuck at `opacity: 0` if a font or image takes too long; width-fitting must re-run once `document.fonts.ready` resolves (pinned in Task 4).
- **Background tab throttling (`dt > 250ms`) & `prefers-reduced-motion: reduce`:** Returning to a backgrounded tab must never multi-step-jump the carousel or explode Canvas fluid particle deltas; reduced motion must render instant transitions in Act 1 (`HOLD=3000ms, TURN=1ms`) and instant static plated dishes in Act 2 with zero continuous rAF (pinned in Task 4 & Task 5).
